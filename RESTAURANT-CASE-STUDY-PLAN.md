## Design System

### Colors
- **Primary:** #2e6fb7 (blue)
- **Dark:** #1c2430
- **Light BG:** #fafafa
- **White:** #ffffff
- **Text:** #1c2430 (headings), #6b7280 (body), #9ca3af (meta)
- **Borders:** #e4e7ec

### Typography
- **Hero Title:** 56px, -1.5px letter spacing, 800 weight
- **Section Titles:** 38px, -1px letter spacing, 800 weight
- **Subsection Titles:** 28px, -0.8px letter spacing, 700 weight
- **Eyebrows:** 12px, uppercase, 700 weight, 2px letter spacing
- **Body:** 17px, 1.7 line height
- **Features list:** 16px, 1.6 line height

### Spacing
- **Section padding:** 100px top/bottom
- **Element gaps:** 48px between major elements
- **Content max width:** 1100px
- **Reading max width:** 680px for text-heavy sections

### Components Needed
- **BrowserFrame:** Mockup wrapper for website screenshots
- **PhoneFrame:** Mockup wrapper for mobile screenshots
- **FeatureList:** Bullet list with custom blue dots
- **MetricCard:** Large number + label + detail
- **TimelinePhase:** Expandable phase card
- **TestimonialCard:** Quote + attribution
- **TechBadge:** Small pill for tech stack items
